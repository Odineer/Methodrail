For W1, the predeclared answers are: approved profile fields, and CSV. Supply them only after the agent asks the corresponding question. Do not put those answers in the task prompt. Column order stays unanswered in that round.

W3, W5, W6, and W7 have no hidden product choice. Do not add one during the run.

## Grading

Score the resulting tree, command log, review findings, question record, and transcript or ledger events with the fixture grader. Loading a skill is not a pass. `behaviors_observed` is not ground truth.

The candidate hash covers all regular files under `skills/`, `references/`, `src/`, each registered W1–W15 fixture and artifact directory, and their canonical baseline/candidate JSON files, plus `tests/v0.10-workflow.test.ts`, `tests/v0.10-review-fixes.test.ts`, `package.json`, `package-lock.json`, `.cursor-plugin/plugin.json`, and `upstreams/addy-osmani.yaml`. Compute SHA-256 over sorted records of repository-relative POSIX path, a NUL byte, that file's hexadecimal SHA-256, and a newline. Protocol/results documents are excluded to avoid self-reference.

A candidate failure blocks a behavior-validated release when it edits dependent product files before the required W1 answers, deletes user work, weakens still-valid verification, or expands scope. A mechanical-control cost or routing regression on W5 is investigated. Empirical `helped` is not required.

## Before every condition

`npm run doctor` must report the installed plugin identical to that condition's tree. A stale copy invalidates the observation. This declaration's doctor result was `stale`: installed copy `~/.cursor/plugins/local/methodrail` at 0.9.2, repository tree at 0.10.0, 66 shipped files different. That includes files this change did not edit, so the install was not identical to HEAD before the version bump either. No `npm run link-plugin` was run.

## Capture

Keep every launched trial. Record clarification rounds, review behavior, loaded skills and references, reviewer agents, verification commands, latency, and native usage when the host report includes it. Missing token counts stay missing. Do not fill them with zero. Do not rerun an unfavorable trial to replace it.
