## Why this plan (context for a fresh model)

Methodrail is a Cursor plugin and portable Agent Skills family. It curates upstream skills (pstack, mattpocock/skills, obra/superpowers, Ponytail, Karpathy-inspired guidelines) into one capability owner per concept, ships a small always-on rule, and generates a per-project harness (`.methodrail/PROJECT.md`, typed knowledge notes, control docs, a project verify skill) through `/methodrail-init`. It is methodology plus harness, not an agent runtime. Read these before touching anything:

- `.methodrail/PROJECT.md` — pointer index and canonical commands
- `README.md`, `CONTRIBUTING.md`, `references/capability-map.md`, `references/methodrail-family-invariant.md`
- `evals/README.md`, `evals/fixtures/README.md`, `docs/internal/v0.9-implementation-plan.md` (the style this plan follows)

State observed on 2026-09-20:

- `npm run check` passes (typecheck, 200 tests, validate, eval rescoring).
- 38 shipped skills (26 explicit-only), ~2,850 lines of skill prose, ~1,600 lines of references.
- Live evidence across every pilot: roughly 8 `helped`, ~26 `neutral`, ~11 `incomplete`, 0 `harmed`. Only `runtime-bug`, `knowledge-refresh`, and `knowledge-dispute` ever produced a reproducible Methodrail outcome gap.
- The v0.9 battery was 8/9 `incomplete`; the results doc attributes most of that to phrase-window graders, not agent behavior (`evals/reports/v0.9-project-artifact-interoperability-pilot-results.md`).
- Every Cursor run is `capture: operator_summary`; `skills_invoked` is often empty. Claude Code has never run. The Ponytail battery never launched.
- The author's installed plugin was a stale 0.9.1 copy for 18 days. Every Cursor observation in that window was made against non-HEAD skills. (Fixed in Stage 0 work; see below.)
- The Methodrail repository's own `.methodrail/` contains only `PROJECT.md`. No typed note has ever accumulated organically anywhere.

Diagnosis: the measurement philosophy is excellent and the measurement instrument is thin. The project has iterated methodology instead of running it. This plan turns the instrument on real work first, then prunes, then distributes.

## Global Constraints

Copy these into your head before every task; they are the repository's standing rules and the plan's non-negotiables.

- No second control plane: no router, workflow engine, daemon, database, consumer CLI, or consumer npm dependency. Hooks in this plan are observational only and must never return `permission`, `deny`, `followup_message`, `updated_input`, or `additional_context`.

## Stage 1 — Session ledger (hook capture)

Purpose: turn Cursor from `operator_summary` into `hook_captured` evidence. After this stage every Cursor session in a Methodrail-harnessed repository leaves a JSONL ledger of skill/reference reads, shell commands with exit codes, subagents, final responses, and stop status, written outside the repo. A collector turns a ledger into an `EvalRun` JSON plus `answer.md` and `command.log.json` artifacts that the existing graders already consume.

Ledger location (default): `${METHODRAIL_LEDGER_DIR:-${XDG_STATE_HOME:-$HOME/.local/state}/methodrail/sessions}/<repo-key>/<conversation_id>.jsonl`, where `repo-key = <basename of workspace root>-<first 12 hex of sha256(realpath(workspace root))>`. Response bodies go beside it under `<conversation_id>.responses/<generation_id>-<seq>.md`.

Gate: the hook writes only if `<workspace_root>/.methodrail` exists (directory or symlink) **or** `METHODRAIL_LEDGER=1`. `METHODRAIL_LEDGER=0` disables regardless. Non-Methodrail projects are never touched.

Events recorded (all observational; verified against https://cursor.com/docs/agent/hooks on 2026-09-20):

| Cursor event | Ledger event | Fields used from stdin |
| --- | --- | --- |
| `sessionStart` | `session_start` | `session_id`, `composer_mode`, base fields |
| `postToolUse` | `tool` | `tool_name`, `tool_input`, `tool_output`, `duration` |
| `postToolUseFailure` | `tool_failure` | `tool_name`, `tool_input`, `failure_type`, `error_message` |
| `subagentStop` | `subagent_stop` | `subagent_type`, `status`, `duration_ms`, `tool_call_count` |
| `afterAgentResponse` | `response` | `text` |
| `stop` | `stop` | `status`, `loop_count` |

Base fields on every Cursor hook payload: `conversation_id`, `generation_id`, `model`, `model_id`, `hook_event_name`, `cursor_version`, `workspace_roots`, `transcript_path`. `subagentStart`, `beforeReadFile`, `beforeShellExecution`, `preToolUse` are permission hooks and are **not used** (invalid JSON from them blocks the action).

Unverified detail to confirm on the first real ledger (Task 1.6): the exact `tool_input` keys per tool. The docs show `Shell → {command, working_directory}`; by analogy `Read/Write/StrReplace/Delete → {path}`, `Grep → {pattern, path}`, `Task → {subagent_type, description}`. The script below reads `tool_input.path ?? tool_input.file_path ?? tool_input.target_file` so a naming mismatch degrades to a missing path, not a crash. `tool_output` for Shell is documented as a JSON string like `{"exitCode":0,"stdout":"…"}`.

```ts
// src/ledger/types.ts
export interface LedgerBase {
  v: 1;
  ts: string;
  conversation_id: string;
  generation_id?: string;
  model?: string;
  workspace_root: string;
}

export type LedgerEvent =
  | (LedgerBase & { event: "session_start"; session_id: string; composer_mode?: string; cursor_version?: string; plugin_root?: string; repo_head?: string })
  | (LedgerBase & { event: "tool"; tool_name: string; path?: string; command?: string; exit_code?: number | null; duration_ms?: number; output_tail?: string })
  | (LedgerBase & { event: "tool_failure"; tool_name: string; path?: string; command?: string; failure_type: string; error_message?: string })
  | (LedgerBase & { event: "subagent_stop"; subagent_type: string; status: string; duration_ms?: number; tool_call_count?: number })
  | (LedgerBase & { event: "response"; text_path: string; sha256: string; chars: number })
  | (LedgerBase & { event: "stop"; status: string; loop_count?: number });

export const LEDGER_EVENTS = new Set(["session_start", "tool", "tool_failure", "subagent_stop", "response", "stop"]);

export type ReadClass =
  | { kind: "skill"; name: string; origin: "plugin" | "project" }
  | { kind: "reference"; rel: string }
  | { kind: "harness"; rel: string }
  | { kind: "other" };
```

```ts
// src/ledger/parse.ts
import { relative, resolve, sep } from "node:path";
import { LEDGER_EVENTS, type LedgerEvent, type ReadClass } from "./types.js";

export function parseLedger(text: string): { events: LedgerEvent[]; malformed: number } {
  const events: LedgerEvent[] = [];
  let malformed = 0;
  for (const line of text.split(/\r?\n/)) {
    if (!line.trim()) continue;
    try {
      const value = JSON.parse(line) as Partial<LedgerEvent>;
      if (value && typeof value === "object" && typeof value.event === "string" && LEDGER_EVENTS.has(value.event) && typeof value.conversation_id === "string") {
        events.push(value as LedgerEvent);
      } else {
        malformed += 1;
      }
    } catch {
      malformed += 1;
    }
  }
  return { events, malformed };
}

const SKILL_RE = /^skills\/([a-z0-9][a-z0-9-]*)\/SKILL\.md$/;
const PROJECT_SKILL_RE = /^(?:\.cursor|\.agents|\.claude)\/skills\/([a-z0-9][a-z0-9-]*)\/SKILL\.md$/;

function relInside(root: string | null, path: string): string | null {
  if (!root) return null;
  const rel = relative(resolve(root), resolve(path));
  if (!rel || rel.startsWith("..") || rel.startsWith(sep)) return null;
  return rel.split(sep).join("/");
}

export function classifyReadPath(path: string, ctx: { pluginRoot: string | null; workspaceRoot: string }): ReadClass {
  const inPlugin = relInside(ctx.pluginRoot, path);
  if (inPlugin) {
    const skill = SKILL_RE.exec(inPlugin);
    if (skill) return { kind: "skill", name: skill[1]!, origin: "plugin" };
    if (inPlugin.startsWith("references/") || inPlugin.startsWith("rules/") || /^skills\/[^/]+\/references\//.test(inPlugin) || /^skills\/[^/]+\/[^/]+\.md$/.test(inPlugin)) {
      return { kind: "reference", rel: inPlugin };
    }
  }
  const inWorkspace = relInside(ctx.workspaceRoot, path);
  if (inWorkspace) {
    const skill = PROJECT_SKILL_RE.exec(inWorkspace);
    if (skill) return { kind: "skill", name: skill[1]!, origin: "project" };
    if (inWorkspace.startsWith(".methodrail/")) return { kind: "harness", rel: inWorkspace };
  }
  return { kind: "other" };
}
```

```js
#!/usr/bin/env node
// scripts/hooks/session-ledger.mjs
// Observational Cursor hook. Appends one JSONL line per event to a ledger
// outside the repository. Never blocks: any failure exits 0 with {}.
// Importable as a module (exports repoKey) without running main().
import { appendFileSync, existsSync, mkdirSync, readSync, realpathSync, writeFileSync } from "node:fs";
import { createHash } from "node:crypto";
import { homedir } from "node:os";
import { basename, dirname, join, resolve } from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";

const OUTPUT_TAIL = 400;

function readStdin() {
  const chunks = [];
  const buf = Buffer.alloc(65536);
  for (;;) {
    let n = 0;
    try {
      n = readSync(0, buf, 0, buf.length, null);
    } catch (error) {
      if (error && error.code === "EAGAIN") continue;
      break;
    }
    if (n <= 0) break;
    chunks.push(Buffer.from(buf.subarray(0, n)));
  }
  return Buffer.concat(chunks).toString("utf8");
}

function main() {
  const raw = readStdin();
  let payload;
  try {
    payload = JSON.parse(raw);
  } catch {
    return;
  }
  if (!payload || typeof payload !== "object") return;
  if (process.env.METHODRAIL_LEDGER === "0") return;

  const workspaceRoot = Array.isArray(payload.workspace_roots) ? payload.workspace_roots[0] : undefined;
  if (typeof workspaceRoot !== "string" || !workspaceRoot) return;
  const harnessPresent = existsSync(join(workspaceRoot, ".methodrail"));
  if (!harnessPresent && process.env.METHODRAIL_LEDGER !== "1") return;

  const conversationId = typeof payload.conversation_id === "string" ? payload.conversation_id : typeof payload.session_id === "string" ? payload.session_id : null;
  if (!conversationId) return;

  const event = translate(payload);
  if (!event) return;

  const repoDir = join(ledgerRoot(), repoKey(workspaceRoot));
  mkdirSync(repoDir, { recursive: true });

  if (event.event === "response") {
    const seq = Date.now().toString(36);
    const rel = join(`${conversationId}.responses`, `${payload.generation_id ?? "gen"}-${seq}.md`);
    mkdirSync(join(repoDir, dirname(rel)), { recursive: true });
    writeFileSync(join(repoDir, rel), event.text);
    event.text_path = rel;
    event.sha256 = createHash("sha256").update(event.text).digest("hex");
    event.chars = event.text.length;
    delete event.text;
  }

  const line = JSON.stringify({
    v: 1,
    ts: new Date().toISOString(),
    conversation_id: conversationId,
    generation_id: typeof payload.generation_id === "string" ? payload.generation_id : undefined,
    model: typeof payload.model === "string" ? payload.model : undefined,
    workspace_root: workspaceRoot,
    ...event,
  });
  appendFileSync(join(repoDir, `${conversationId}.jsonl`), line + "\n");
}

function translate(p) {
  const input = p.tool_input && typeof p.tool_input === "object" ? p.tool_input : {};
  const path = firstString(input.path, input.file_path, input.target_file);
  const command = firstString(input.command);
  switch (p.hook_event_name) {
    case "sessionStart":
      return {
        event: "session_start",
        session_id: String(p.session_id ?? p.conversation_id ?? ""),
        composer_mode: firstString(p.composer_mode),
        cursor_version: firstString(p.cursor_version),
        plugin_root: pluginRoot(),
      };
    case "postToolUse": {
      const out = { event: "tool", tool_name: String(p.tool_name ?? ""), path, command, duration_ms: numberOr(p.duration) };
      if (typeof p.tool_output === "string") {
        try {
          const parsed = JSON.parse(p.tool_output);
          if (parsed && typeof parsed === "object") {
            if (typeof parsed.exitCode === "number") out.exit_code = parsed.exitCode;
            const stdout = typeof parsed.stdout === "string" ? parsed.stdout : "";
            if (process.env.METHODRAIL_LEDGER_VERBOSE === "1") out.output_tail = stdout.slice(-4000);
            else if (out.tool_name === "Shell") out.output_tail = stdout.slice(-OUTPUT_TAIL);
          }
        } catch {
          // tool_output is not JSON for every tool; exit code stays undefined
        }
      }
      return out;
    }
    case "postToolUseFailure":
      return { event: "tool_failure", tool_name: String(p.tool_name ?? ""), path, command, failure_type: String(p.failure_type ?? "error"), error_message: firstString(p.error_message)?.slice(0, OUTPUT_TAIL) };
    case "subagentStop":
      return { event: "subagent_stop", subagent_type: String(p.subagent_type ?? ""), status: String(p.status ?? ""), duration_ms: numberOr(p.duration_ms), tool_call_count: numberOr(p.tool_call_count) };
    case "afterAgentResponse":
      return typeof p.text === "string" ? { event: "response", text: p.text } : null;
    case "stop":
      return { event: "stop", status: String(p.status ?? ""), loop_count: numberOr(p.loop_count) };
    default:
      return null;
  }
}

function ledgerRoot() {
  if (process.env.METHODRAIL_LEDGER_DIR) return resolve(process.env.METHODRAIL_LEDGER_DIR);
  const state = process.env.XDG_STATE_HOME || join(homedir(), ".local", "state");
  return join(state, "methodrail", "sessions");
}

export function repoKey(workspaceRoot) {
  let real = workspaceRoot;
  try {
    real = realpathSync(workspaceRoot);
  } catch {
    // keep the logical path
  }
  return `${basename(real)}-${createHash("sha256").update(real).digest("hex").slice(0, 12)}`;
}

function pluginRoot() {

}
```

```ts
const OBSERVATIONAL_HOOK_EVENTS = new Set([
  "sessionStart", "sessionEnd", "postToolUse", "postToolUseFailure", "subagentStop",
  "afterShellExecution", "afterMCPExecution", "afterFileEdit", "afterAgentResponse", "afterAgentThought", "preCompact", "stop",

function validateHooks(root: string): ValidationIssue[] {
  const manifestPath = join(root, ".cursor-plugin", "plugin.json");
  if (!existsSync(manifestPath)) return [];
  let hooksRel: unknown;
  try {
    hooksRel = (JSON.parse(readFileSync(manifestPath, "utf8")) as Record<string, unknown>).hooks;
  } catch {
    return [];
  }
  if (hooksRel === undefined) return [];
  if (typeof hooksRel !== "string") return [issue(manifestPath, "plugin.json hooks must be a path string")];
  const hooksPath = join(root, hooksRel);
  if (!existsSync(hooksPath)) return [issue(hooksPath, "hooks config referenced by plugin.json does not exist")];
  const issues: ValidationIssue[] = [];
  let config: Record<string, unknown>;
  try {
    config = JSON.parse(readFileSync(hooksPath, "utf8")) as Record<string, unknown>;
  } catch {
    return [issue(hooksPath, "hooks.json is not valid JSON")];
  }
  const hooks = config.hooks;
  if (hooks === null || typeof hooks !== "object") return [issue(hooksPath, "hooks.json requires a hooks object")];
  for (const [event, entries] of Object.entries(hooks as Record<string, unknown>)) {
    if (!OBSERVATIONAL_HOOK_EVENTS.has(event)) {
      issues.push(issue(hooksPath, `${event} is not an observational hook event; Methodrail hooks must stay observational`));
    }
    if (!Array.isArray(entries)) {
      issues.push(issue(hooksPath, `${event} must be an array of hook entries`));
      continue;
    }
    for (const entry of entries) {
      const command = (entry as Record<string, unknown>)?.command;
      if (typeof command !== "string") {
        issues.push(issue(hooksPath, `${event} entry requires a command string`));
        continue;
      }
      const script = command.split(/\s+/)[0] ?? "";
      if (!existsSync(join(root, script))) issues.push(issue(hooksPath, `${event} command ${script} does not exist`));
      if ((entry as Record<string, unknown>).timeout === undefined) issues.push(issue(hooksPath, `${event} entry must declare a timeout`));
      if ((entry as Record<string, unknown>).failClosed === true) issues.push(issue(hooksPath, `${event} entry must not fail closed`));
    }
  }
  return issues;
}
```

Mapping rules (implement exactly):
- `skills_invoked`: unique skill names from `tool` events with `tool_name === "Read"` whose `path` classifies as `skill` (plugin or project), in first-seen order.
- `references_loaded`: unique `rel` from `reference` and `harness` classes, first-seen order.
- `tools_used`: unique lowercased `tool_name`s.
- `subagents_used`: count of `subagent_stop` events.
- `commandLog`: one `CommandLogEntry` per Shell `tool`/`tool_failure` event: `{ command, exit_status: exit_code ?? null, stdout: output_tail, phase }`. `phase` heuristic: `repro` if the command appears before the first `Write`/`StrReplace`/`Delete` tool event and matches `/test|node |npm run|pytest|cargo|go test|make/`; `regression`/`verify` if after the first edit and matches the same regex (first such command after an edit is `regression`, later ones `verify`); otherwise `other`. `verification_steps` = the entries with phase in `{repro, regression, verify}` as `VerificationRecord`s.
- `answer`: contents of the last `response` event's `text_path`, read from `responsesDir`.
- `started_at`/`ended_at`/`latency_ms`: first event `ts`, last `stop` (or last event) `ts`, difference in ms.
- `outcome`: first 300 chars of the answer or `""`. `evidence: []`, `failure_modes: []`, `behaviors_observed` omitted.
- `provenance: "live"`, `capture: "hook_captured"`, `model` from the first event with `model`.

## Risk register

- **Cursor does not load a symlinked plugin.** Control: Task 0.2 branch 2b (clone + doctor same-HEAD acceptance).
- **Hooks from plugins do not fire, or `node` is not on the hook `PATH`.** Control: wrapper searches common locations and exits 0; Task 1.6 isolates plugin-vs-script with a project-level `.cursor/hooks.json`; record the finding; if plugin hooks cannot fire at all, ship the same `hooks.json` as an optional integration that `methodrail-init` installs into `.cursor/hooks.json` of consuming repos, with the same allowlist validated.
- **`tool_input` key names differ from the assumption.** Control: `firstString(path, file_path, target_file)`; Task 1.6 confirms and patches.
- **Subagent events are not separable per run.** Control: per-worktree `METHODRAIL_LEDGER_DIR`; verified before the first battery.
- **Ledger leaks sensitive content.** Control: outside the repository; only Shell `output_tail` (400 chars) by default; responses stored but never committed except pilot fixtures; README disclosure and off switch.
- **Grader widening rewards Methodrail.** Control: artifact gating on every widened check; adversarial negatives; both conditions graded by the same code; before/after table published; `harmed` reported if it appears.
- **Completion report bloats simple work.** Control: two-line form for tiny changes; complexity eval guards `simple-change`.
- **Knowledge loop yields nothing.** That is a valid result; write it down. Do not manufacture notes to have data.
- **Pruning removes something a user relies on.** Control: experimental tier before removal; criteria written before classification; removals one commit each.
